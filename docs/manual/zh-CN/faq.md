# 常见问题排查手册

## 性能瓶颈

### 现象：帧率下降或输入卡顿

排查步骤：

1. 确认是否在 `draw()` 中做了大量对象创建
2. 检查是否频繁加载同一资源而未命中缓存
3. 检查节点树规模与 `zIndex` 变更是否过于频繁
4. 使用浏览器 DevTools 或小游戏性能面板观察主线程占用
5. 打开 Logger 面板查看是否存在资源加载或错误重试

解决建议：

- 将高频对象改为复用
- 启用批量预加载
- 降低每帧字符串拼接和日志量
- 将复杂碰撞改为分层检测或 `SpatialGrid`

## 渲染错误

### 现象：节点可见但没有被绘制

重点检查：

- `visible` 是否为 `false`
- `alpha` 是否小于等于 `0`
- 节点 `width` / `height` 是否未设置
- `draw()` 是否真正输出绘制命令
- 父节点是否被提前隐藏或销毁

### 现象：层级显示顺序不正确

重点检查：

- 是否正确设置 `zIndex`
- 是否在运行时动态修改 `zIndex`
- 命中逻辑是否通过 `UIManager` 管理

当前版本已经在 `Node` 中处理 `zIndex` 标脏重排，但业务层仍需保证层级设计清晰。

## 脚本异常

### 现象：场景切换后交互失效

排查步骤：

1. 检查监听器是场景级还是系统级
2. 若为 UI 系统，确保使用 `persistent` 监听器
3. 检查场景切换时是否重新注册了业务输入事件

### 现象：`update()` 没有执行

重点检查：

- 是否调用了 `engine.start()`
- 当前场景是否已通过 `setScene()` 或 `pushScene()` 进入栈顶
- 子类 `update(dt)` 是否误删 `super.update(dt)`

## 资源加载失败

### 现象：`loadTexture()` 或 `loadJSON()` 抛错

排查步骤：

1. 检查 URL 是否与产物目录一致
2. 检查小游戏平台是否允许访问该资源路径
3. 检查本地服务器是否正确提供静态文件
4. 查看 `Network` 模块日志输出

### 现象：批量加载后看似成功但部分资源不可用

当前版本的 `loadAll()` 已改为任意任务失败就整体抛错。若遇到该问题，通常是业务层忽略了 Promise 异常。应使用：

```ts
try {
  await engine.loader.loadAll(tasks, onProgress);
} catch (error) {
  logger.error('preload failed: %o', error);
}
```

## 输入异常

### 现象：UI 点击位置偏移

排查步骤：

1. 检查画布样式缩放与逻辑分辨率是否一致
2. 检查平台返回的 `pixelRatio`
3. 检查业务代码是否重复缩放触点坐标

`Input` 已在内部按像素比转换坐标，业务层通常不需要再次乘缩放。

## 音频异常

### 现象：背景音乐无法播放

排查步骤：

1. 检查资源路径
2. 检查宿主环境是否要求用户交互后才允许播放
3. 确认未提前调用 `destroy()`

解决建议：

- 在首次点击后再执行 `audio.play()`
- 对小游戏环境增加首帧交互提示

## 存储问题

### 现象：调用 `Storage.clear()` 后其他数据丢失

当前版本已修复越权清理问题，只会清除当前前缀命名空间下的数据。如果仍有异常，请检查：

- 是否多个系统共享了相同 `prefix`
- 是否直接调用了平台层 `clearStorage()`

## 诊断工具使用

### Logger 调试面板

适合查看：

- 开发态模块日志
- 资源请求失败
- 渲染与碰撞异常提示

### 浏览器 DevTools

适合查看：

- 帧时间
- 内存快照
- 网络请求
- 控制台异常

### 小游戏开发者工具

适合查看：

- 平台 API 调用
- 真机兼容性
- 本地缓存
- 包体与资源加载

## 何时需要扩展引擎

如果项目出现以下需求，建议以插件或二次开发方式扩展，而不是误用现有轻量 API：

- 大规模骨骼动画
- 真实物理世界与刚体约束
- 复杂着色器和 3D 管线
- 在线联机状态同步
