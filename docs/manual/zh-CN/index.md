# Lite Game Engine 文档中心

Lite Game Engine 是一个面向微信小游戏、抖音小游戏和 H5 的轻量级 2D 游戏引擎，核心技术栈为 TypeScript、Canvas 2D 与 esbuild。本手册覆盖真实可用的运行时能力、开发流程、API 和故障排查方法，帮助开发者以代码驱动方式完成跨端 2D 游戏项目交付。

## 文档范围

- 技术架构：解释 `Engine`、渲染、输入、资源、音频、碰撞、日志、平台适配等模块
- 环境搭建：说明依赖安装、编译命令、目录结构、模板创建和调试工具
- 基础教程：从零创建一个可运行的 2D 场景并完成构建发布
- API 参考：按模块整理公开类、类型和核心方法
- FAQ：汇总性能、渲染、脚本、资源和平台兼容问题

## 能力边界

本仓库当前实现的是 2D Canvas 引擎，而不是通用 3D 引擎。以下能力在当前版本中未实现：

- 3D 场景、网格、骨骼动画、PBR 材质
- DirectX 12、Vulkan、OpenGL 4.5 的原生渲染后端
- 场景编辑器、材质编辑器、动画编辑器
- 内置脚本虚拟机、原生物理求解器、网络同步框架

当前图形能力完全依赖目标平台提供的 Canvas 2D 实现。H5 运行于浏览器图形栈，小程序运行于宿主环境封装的 2D 画布接口。

## 支持矩阵

| 类别 | 当前支持 |
| --- | --- |
| 开发操作系统 | Windows、macOS、Linux |
| 运行目标 | H5、微信小游戏、抖音小游戏 |
| 核心语言 | TypeScript |
| 图形接口 | Canvas 2D |
| 构建工具 | esbuild |
| 自动化测试 | Vitest |

## 建议硬件

| 场景 | 最低建议 | 推荐配置 |
| --- | --- | --- |
| 文档阅读 / 代码开发 | 双核 CPU、4GB RAM | 四核 CPU、8GB RAM |
| H5 调试 | 集成显卡、现代浏览器 | 任意支持硬件加速的浏览器 |
| 小游戏调试 | 官方开发者工具可运行 | 8GB RAM 以上以减少热重载卡顿 |

## 阅读路径

1. 先阅读 `architecture.md` 理解模块关系与性能约束
2. 根据 `setup.md` 安装依赖并完成首次构建
3. 按 `tutorial.md` 创建第一个可运行的 2D 场景
4. 在开发过程中查阅 `api.md` 和 `faq.md`
